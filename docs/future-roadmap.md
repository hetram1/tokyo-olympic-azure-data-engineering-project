# Future extensions outside the verified release

The earlier main-branch README proposed Neo4j/knowledge-graph analysis, vector
retrieval, RAG/GraphRAG, LangGraph orchestration and a FastAPI service. Those ideas
remain future work; they are not implemented or claimed by this release. The
current scope is data quality, country analytics/ML, Azure ingestion, a prepared
PySpark path and the native Power BI report. Resolve the documented Databricks
identity prerequisite and verify cloud execution before claiming a complete Azure
pipeline. Power BI Service publication is separate from the local Desktop report.
